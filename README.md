# Lead Bot

## Проблема

Менеджеры получают заявки от клиентов без информации о бюджете и сроках. Из-за этого сложно быстро определить, насколько клиент заинтересован в покупке, и расставить приоритеты. Пока менеджер обрабатывает другие заявки, горячий клиент может уйти к конкурентам, и компания теряет потенциальную продажу.

## Решение

Клиент проходит мини-квиз в Telegram-боте, где отвечает на вопросы о бюджете и сроках. Бот обрабатывает ответы с помощью ИИ-модели, определяет, насколько клиент горячий, и записывает данные в таблицу.

Если заявка горячая, менеджер получает уведомление в Telegram, чтобы быстрее связаться с клиентом.

## Что умеет

- Проводить мини-квиз для сбора информации о бюджете и сроках клиента.
- Обрабатывать ответы клиента с помощью ИИ-модели.
- Переводить бюджет из сумов в доллары по курсу Центрального банка.
- Определять горячие заявки: клиенту нужно срочно, а бюджет составляет от 400 $ или не указан.
- Записывать данные о клиентах и результаты обработки в таблицу.
- Отправлять уведомления менеджеру в Telegram при поступлении горячей заявки.

## Как запустить

1. Установить библиотеки: `pip install -r requirements.txt`
2. Создать файл `.env` с переменными `BOT_TOKEN` и `WEBHOOK_URL`.
3. В n8n настроить и запустить отдельный workflow `razbor-zayavki` (пока не включён в репозиторий).
4. Запустить бота: `python bot.py`

## Ограничения

- Анкеты хранятся в памяти — при перезапуске бота данные незавершённых анкет теряются.
- Бот работает только при включённом ноутбуке и запущенных боте и n8n.
- Для запуска необходимо отдельно настроить workflow `razbor-zayavki` в n8n.
